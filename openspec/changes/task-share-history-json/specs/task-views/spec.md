# task-views

## ADDED Requirements

### Requirement: A row's menu shares the task

A row's or card's menu SHALL offer Share, opening the same Share menu as the task screen.

#### Scenario: Copy key and title from a row

- **WHEN** a person opens a row's menu for infra-1 "Fix login", picks Share and then Copy key and title
- **THEN** the clipboard holds `infra-1 Fix login`
