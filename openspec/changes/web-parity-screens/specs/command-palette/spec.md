# command-palette

## MODIFIED Requirements

### Requirement: Global commands

Whatever screen shows, the palette SHALL offer quick add, templates, switching to each saved context, the theme
choices, settings, the inbox and my work once they are routed, Statistics and Connect an agent.

#### Scenario: Theme

- **WHEN** a person opens the palette and runs "Dark theme"
- **THEN** the app switches to the dark theme

#### Scenario: Statistics

- **WHEN** a person opens the palette and runs "Go to Statistics"
- **THEN** the Statistics screen opens
