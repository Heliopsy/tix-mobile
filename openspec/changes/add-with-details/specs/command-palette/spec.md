# command-palette

## MODIFIED Requirements

### Requirement: Global commands

Whatever screen shows, the palette SHALL offer quick add, Add with details, templates, switching to each saved
context, the theme choices, settings, and the inbox and my work once they are routed.

#### Scenario: Theme

- **WHEN** a person opens the palette and runs "Dark theme"
- **THEN** the app switches to the dark theme

#### Scenario: Add with details

- **WHEN** a person opens the palette and runs "Add with details"
- **THEN** the Add with details form opens
